## Running Locally

This application requires Node.js v18.17+.

```bash
git clone https://github.com/codewdhruv/codewdhruv.com.git
cd .io
bun install
bun run setup # Remove all of my personal information
bun dev
```

Create a `.env.local` file similar to [`.env.example`](https://github.com//.io/blob/main/.env.example).
